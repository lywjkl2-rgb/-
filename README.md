# ⚡ 회로 튜터 — 원리를 풀어 주는 회로 시뮬레이터

전기공학을 공부할 때 **회로가 어떤 원리와 순서로 동작하는지**, **각 소자가 왜 그 자리에 있는지**를
수식과 함께 단계별로 풀어 주는 학습용 회로 시뮬레이터입니다.

회로를 넣는 방법은 두 가지입니다.

1. **직접 설계** — 브라우저의 회로도 편집기에서 부품을 배치하고 배선합니다.
2. **교재 그림 가져오기** — 회로 사진·스캔 이미지·PDF를 올리면 Claude(비전)가 회로도를 읽어
   넷리스트로 바꾸고, 편집 가능한 회로도로 자동 배치합니다. SPICE 넷리스트 붙여넣기도 지원합니다.

## 무엇을 보여 주나

회로를 바꿀 때마다 자동으로 다시 해석하고, 오른쪽 패널에 다음을 보여 줍니다.

| 단계 | 내용 |
|---|---|
| 1. 회로 구성 파악 | 소자·노드·전원 목록, 연결 오류 경고 |
| 2. 회로 구조와 동작 원리 | 분압기, LED 전류 제한, RC/RL 시정수, RLC 공진(감쇠비), 반파·브리지 정류, 제너 레귤레이터, 반전/비반전/가산 증폭기, 적분기, 비교기, 공통 이미터 증폭기, 트랜지스터 스위치, 휘트스톤 브리지, 직렬·병렬 등가 저항 등 **패턴을 인식해 원리와 공식**을 설명 |
| 3. 회로 방정식 세우기 | 수정 절점 해석법(MNA): 노드 정의 → 노드별 KCL 식 → 전원 제약식 → 비선형 소자 모델 → $\mathbf{A}\mathbf{x}=\mathbf{b}$ 행렬 (LaTeX) |
| 4. 풀이 결과 | 노드 전압, 소자별 전류·전력을 옴의 법칙 등에 **숫자를 대입한 식**으로 표시, 전력 평형(에너지 보존) 검산 |
| 5. 전류의 흐름과 순서 | 전원 (+)에서 출발해 어떤 소자를 어떤 순서로 지나며 전압이 얼마씩 떨어지는지(KVL), 노드별 전류 분기(KCL) 표 |
| 6. 시간 응답 | t = 0⁺ 상태 → 시정수에 따른 변화(τ, 2τ … 5τ 표) → 다이오드 도통·스위치 전환 같은 **사건의 시간 순서** → 최종 상태와 저장 에너지 |
| 7. 주파수 응답 | 보드 선도, 저역/고역/대역 통과 판정, −3 dB 주파수, 위상 |

그 밖에

- **소자 역할 카드**: 소자마다 "전류 제한 저항", "평활 커패시터", "가상 접지를 유지하는 반전 증폭기"처럼 회로 안에서의 역할과 동작점 값
- **회로도 위 애니메이션**: 노드 전압에 따른 배선 색, 전류 크기·방향에 따른 점의 흐름, LED 발광, 시간 재생 슬라이더
- **파형(오실로스코프)**: 노드 전압·소자 전류를 골라 시간 파형 비교
- **AI 튜터**: 화면의 회로와 시뮬레이션 결과를 근거로 질문에 답하는 Claude 채팅 (수식은 LaTeX)
- 회로 파일 저장/열기(JSON), SPICE 넷리스트·SVG 내보내기, 실행 취소, 자동 저장
- 15개 교과서 예제(분압기, RC 충·방전, RL, RLC, 정류기, 제너, 연산증폭기, BJT 증폭기/스위치, 휘트스톤 브리지 …)

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev          # 웹(5173) + API 서버(8787) 동시 실행 → http://localhost:5173
```

이미지/PDF 인식과 AI 튜터는 Claude API를 사용하므로 서버를 실행할 때 자격 증명이 필요합니다.

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # 또는 `ant auth login` 프로필
npm run dev
```

자격 증명이 없어도 회로 설계·시뮬레이션·해설·SPICE 가져오기는 모두 동작합니다.

배포용:

```bash
npm run build        # dist/ 생성
npm start            # http://localhost:8787 에서 화면과 API를 함께 제공
```

환경 변수: `PORT`(기본 8787), `CLAUDE_MODEL`(기본 `claude-opus-5-5`).

테스트: `npm test` (시뮬레이터 정확도, 패턴 인식, 예제 회로, SPICE·인식 결과 변환·자동 배치 검증)

## 사용법

- **부품 배치**: 왼쪽 팔레트에서 고르거나 숫자 단축키(1 저항, 2 커패시터, 3 인덕터, 4 전압원, 5 전류원,
  6 다이오드, 7 NPN, 8 연산증폭기, 9 스위치, 0 접지) → 캔버스 클릭. `R` 회전, `F` 뒤집기, `Esc` 종료
- **배선**: `W` 또는 핀에서 드래그 시작 → 클릭으로 꺾기 → 핀·배선에 닿으면 연결. `Space`로 꺾는 방향 전환
- **값 입력**: `4.7k`, `10u`, `100n`, `2.2M`, `4k7` 같은 SI/RKM 표기 사용 가능
- **교재 그림 가져오기**: 상단 "이미지·PDF에서 가져오기" → 파일 끌어놓기/붙여넣기 → (PDF는 페이지 선택)
  → 회로 부분만 드래그해 자르기 → "회로 인식". 결과 위에 원본 그림을 겹쳐 띄워 비교·수정할 수 있습니다.
- 스위치를 더블클릭하면 열림/닫힘이 바뀌고, 스위치 속성의 "전환 시각"을 정하면 과도 해석 도중에 바뀝니다.

## 구조

```
src/
  engine/       시뮬레이터 (브라우저·Node 공용, 의존성 없음)
    components.ts  소자 정의(핀·속성), SI 단위 파싱/표기
    netlist.ts     회로도(배선 기하) → 넷리스트(노드 번호)
    simulator.ts   MNA: DC(뉴턴–랩슨, pnjlim, 전원 스텝핑) / 과도(사다리꼴·후진 오일러) / AC(복소 MNA)
    models.ts      다이오드·LED·제너, BJT(Ebers–Moll), 연산증폭기(포화 tanh) 모델
    linalg.ts      가우스 소거 (실수·복소수)
  analysis/     해설 엔진
    patterns.ts    교과서 회로 패턴 인식과 원리·공식·소자 역할
    topology.ts    그래프 도우미, 테브난 등가 저항(시정수 계산)
    explain.ts     단계별 해설 보고서 (한국어 + LaTeX)
  editor/       SVG 회로도 편집기, 전류 흐름 계산, 실행 취소
  importer/     SPICE 파서/내보내기, 이미지 인식 결과 변환, 넷리스트 → 회로도 자동 배치
  ui/           KaTeX 렌더링, 파형·보드 선도, 가져오기 대화상자
server/index.ts Claude API 프록시 (/api/recognize, /api/tutor) + 정적 파일
```

### 이미지 인식 방식

1. 브라우저에서 이미지/PDF 페이지를 렌더링하고 사용자가 고른 영역을 PNG로 자릅니다 (pdf.js).
2. 서버가 Claude(`claude-opus-5-5`, 구조화 출력 JSON 스키마)에게 소자 종류·값·핀별 넷 이름·그림 속 위치를 받아옵니다.
   API 키는 서버에만 있고 브라우저로 보내지 않습니다.
3. 클라이언트가 위치를 격자에 맞추고, 각 핀이 연결 상대 쪽을 향하도록 회전을 고른 뒤,
   넷마다 최소 신장 트리를 ㄱ자 배선으로 그립니다. 다른 넷과 겹치면 우회하고, 그래도 안 되면 넷 라벨로 대체합니다.
4. 완성된 회로도를 다시 넷리스트로 추출해 원래 연결과 같은지 검증합니다.

> 인식 결과는 틀릴 수 있습니다(특히 손글씨, 흐린 스캔, 교차 배선). 해석 전에 원본과 값·연결을 꼭 확인하세요.

### 시뮬레이션 모델의 한계

- 연산증폭기는 이득 $10^5$, 출력 $\pm V_{sat}$ 포화만 고려한 이상적 모델 (대역폭·슬루율·전원 핀 없음)
- BJT는 Ebers–Moll 기본 모델 (Early 효과·접합 용량 없음), 다이오드는 접합 용량 없음
- 과도 해석은 고정 시간 간격 (수렴 실패 시 자동으로 간격을 쪼갬)
